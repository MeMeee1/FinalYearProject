## 🚀 Getting Started in 3 Steps

### Step 1: Install
```bash
cd vendors
npm install
```

### Step 2: Configure
Create `.env.local`:
```env
NEXT_PUBLIC_API_URL=http://localhost:3001
```

### Step 3: Run
```bash
npm run dev
```

Visit: http://localhost:3000
